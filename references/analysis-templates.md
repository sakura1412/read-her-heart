# 需求分析模板

## 5W2H 快速表

| 项目 | 要回答的问题 |
| --- | --- |
| Who | 谁受影响、谁使用、谁付费或承担成本？ |
| What | 现象、任务与拟议方案分别是什么？ |
| Why | 为什么现在解决，根因是什么，不做的代价是什么？ |
| When | 在什么触发时机、频率和业务窗口发生？ |
| Where | 哪个端、页面、渠道或业务环节？ |
| How | 用户目前如何完成任务，方案如何改变流程？ |
| How much | 覆盖多少人，价值、成本、风险和资源量级如何？ |

## RICE 口径

| 维度 | 建议口径 |
| --- | --- |
| Reach | 固定时间窗内被影响的目标用户或事件数 |
| Impact | 对核心目标的单用户影响，使用约定的相对分级 |
| Confidence | 证据可信度；高=数据/实验，中=多方一致反馈，低=假设 |
| Effort | 跨职能总投入，如人周或人月 |

RICE 只用于同一口径下的相对比较。不要将不同时间窗、不同用户群或不同 Effort 单位混在同一排序中。
