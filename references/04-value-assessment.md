# 04 Value Assessment — 价值评估

## 目标

回答七层决策的第 2 层：**问题是否值得解决？** 问题存在不代表值得投入产品资源。

## 固定价值判断链

对每个原子需求按以下顺序填写，不得把多个需求混在一条链中：

**需求 → 价值假设 → 影响指标 → 当前基线 → 预期变化 → 证据来源 → 可信度**

- **价值假设**：如果做了什么，将为哪类用户或业务带来什么变化，以及为什么；关键假设赋予/沿用 H 编号，供 07 与决策引用。
- **影响指标**：能够反映价值是否发生的指标、口径和时间窗口；无法量化时给出可观察行为或结果信号。
- **当前基线**：当前值、周期和适用范围；没有可靠数据时写“未知/待测”。
- **预期变化**：方向、幅度或区间和观察周期；没有依据时只写定性假设并降低可信度。
- **证据来源**：引用[台账](evidence-ledger.md)的 E@版本及必要发现摘要，时间/窗口、范围、偏差与支持/反证在台账维护；只有纯假设时写“暂无证据，H 待验证”，不把猜测当 E。
- **可信度**：高 / 中 / 低及理由；缺基线、变化依据或直接证据时不能为高。

同时检查用户损失、业务收益、战略一致性、影响范围、机会成本、不解决的后果和价值兑现机制。合规需求可以用义务满足和损失规避表达价值，但必须确认适用范围和最低充分要求。

## 可选外部扫描

当竞品格局、市场趋势或监管变化可能实质改变价值假设、机会成本或合规义务，且用户已要求或授权查询/总结公开信息时，读取[外部扫描规则](external-scan.md)，仅核查与本需求相关的问题。外部材料可支持背景和机会判断，但不能代替本产品的用户证据、指标基线或预期变化依据；监管适用性须保留法务/合规确认。未扫描或没有可靠来源时标注未知，不推断“无竞品、无趋势、无法规变化”。

市场/0→1价值假设按[研究取证与分级](market-user-research.md#市场证据的可信度分级)核对原始出处、方法/样本、时间/地区、细分人群与独立性，E强度不等于本假设可信度。区分行业规模、可触达人群、真实任务、使用意愿及支付证据；大盘增长或竞品成功不能直接换算收入、需求覆盖或转化。明确不适用材料只作背景，不用高权威标签掩盖范围不匹配。

## 阶段判断

- **成立**：价值机制、指标和证据足以继续比较方案。
- **部分成立/待验证**：存在合理价值假设，但关键基线、覆盖或兑现机制缺失；进入 07 设计验证。
- **不成立**：进入不投入，不因方案新颖或实现简单而继续。

不得伪造精确百分比、市场规模、收入提升或节省金额。

## 已有 PRD 的范围变更

按[变更联动规则](requirement-change.md#范围变更的联动更新)只复核受影响的价值假设与指标。沿用指标编号或名称及口径版本，核对人群、分子/分母、时间窗口、基线、目标与数据来源的适用性；新旧口径不可直接比较时说明原因，新范围缺基线则待测，不改写历史结果或凭范围变化重定成功标准。只回到确受影响的判断，不重评无关价值链；强制范围仅维护已有指标与真实未知，不恢复被跳过的价值门槛。
