# 宿主适配与能力降级

Codex、WorkBuddy 和 Claude Code 共用 `SKILL.md` 及其引用的资源，产品判断、强制执行范围、PRD 类型选择和安全规则一致。安装与调用入口见 [README](../README.md#快速开始)；`agents/openai.yaml` 仅为 Codex 的可选展示/调用元数据，其他宿主不需要执行它，也不依赖另建 Agent、插件或配置文件。

## 路径与执行

- **Skill 根目录**取本次加载的 `SKILL.md` 所在目录；引用的相对路径相对于包含该引用的文件解析。无法定位时先用宿主提供的技能位置或文件读取能力查明，不猜 `~/.codex` 等固定目录，不因文件没在业务 cwd 下就断言缺失。
- **业务输出目录**与安装目录分开。Backlog、证据及 PRD 仍使用已授权的项目私有目录，不能因跨宿主适配写进公开 Skill 仓库。目录有空格或中文时按实际 shell 正确引用；Windows 使用真实盘符路径，不把示例中的 POSIX 路径当实际位置。
- 执行配套脚本时优先传脚本的绝对路径，不要求改变业务 cwd。Python 解释器按环境中已确认的 `python3`、`python` 或 `py -3` 选择；使用宿主实际执行工具，不硬编码某个平台的工具 API。
- 能读取支持文件不代表能运行脚本；脚本可运行也不代表有写入或联网权限。仅在相应操作需要时核对，不在每次需求分析前安装依赖或遍历所有工具。

## 按能力选择处理方式

| 当前需要 | 有能力且已获相应授权 | 能力缺失或执行受限 |
| --- | --- | --- |
| 澄清关键歧义 | 使用宿主实际提供的结构化提问能力 | 按[问答规则](clarification-dialogue.md)用简短文本给两个建议选项并允许自由输入；不伪造按钮，不将沉默当回答。需要用户选择的 PRD 类型仍保留三个类型的可选性。 |
| 系统实查 | 使用可访问目标环境的浏览器或连接器，保持既有只读/授权边界 | 标“未实查”，按用户提供的文档、截图、描述继续并保留来源；URL、登录信息或宿主名称都不证明已访问。用户自行登录，不要求把密码发进聊天。 |
| 外部扫描 | 在原有授权范围内使用实际搜索/浏览工具，注明来源和时效 | 用已有资料并标“未独立核验”；不把记忆当实时搜索结果。无需为继续分析自动安装连接器。 |
| Backlog 保存或续接 | 按[持久化规则](requirement-state.md)运行配套脚本，确认真实写入及读取结果 | 缺 Python、执行工具或写权限时交付卡片草稿并明确“尚未持久化”。能读取则可分析已有记录；不能伪造修订号、历史快照或绕过并发校验手写已保存状态。 |
| PRD 文件/PDF | 用宿主现有文件与导出能力，沿用 [10 的快速交付及最小检查](10-prd-generation.md#pdf-文件交付两种模式通用) | 没有文件能力时交付正文草稿并说明源稿文件与 PDF 均未生成；能保存源稿但不能导出时交付真实源稿并标 PDF 未完成。不伪造下载链接，不自动上传外部转换服务。 |
| Mermaid 与独立反方评审 | 有相应能力时按现有模块执行 | 分别按[逻辑图](mermaid-diagrams.md#渲染与轻量核对)提供等价表格、按[反方评审](premortem-review.md)标明“单模型反方复核，非独立评审”，不冒充渲染成功或独立专家结论。 |

工具不可用不会改变普通模式的产品门槛，也不会把强制模式变回价值评估。继续完成不依赖该工具的工作，只对确受影响的事实或交付标明缺口；需要用户回答的关键选择仍等实际回复后续接。

## 文件交付与跨会话

提供宿主支持的真实附件或文件链接。宿主不支持可点击本地链接时给实际文件路径并明确打开方式，不把文件路径包装成不存在的公网下载地址；仅正文、导出命令或文件名不等于文件交付。没有可访问 PDF 时，不宣称默认 PDF 交付已完成。

更换客户端、设备或会话不会自动迁移项目资料。先定位并读取同一份获授权的项目记录；无法访问原目录时说明未加载，使用用户提供的副本也要核对版本和来源，不能从旧聊天推定已同步。桌面安装成功不等于对应 Web/云端会话也有同样的技能、文件或工具。
